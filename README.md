# One For All Survival

Mod Minecraft Forge pour la version 1.20.1 (Forge 47.4.28, Java 17, mappings officiels).

## Commandes

```bash
./gradlew build
```

Le jar du mod est produit dans `build/libs/`.

```bash
./gradlew runClient
```

Lance un client de développement, avec le dossier `run/` comme répertoire de travail.
